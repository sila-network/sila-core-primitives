# SILA Keccak-256 V1 — المواصفة المرجعية

**الحالة: مسودة تقنية، غير معتمدة للإنتاج.**

## الوظيفة

حساب بصمة Keccak-256 لبيانات بايتية محددة بدقة. البصمة طولها 32 بايت.
هذا التنفيذ يحافظ على نفس نتائج خوارزمية Keccak-256 المعروفة، ولا يبتكر
خوارزمية تشفير جديدة. تختلف Keccak-256 عن SHA3-256 في قواعد الحشو.

## المعايير المثبتة

| العنصر | القيمة |
|---|---|
| الخوارزمية | Keccak-256 |
| التبديل الداخلي | Keccak-f[1600] |
| الجولات | 24 |
| معدل الامتصاص | 136 بايت |
| السعة | 512 بت |
| طول الناتج | 32 بايت |
| ترتيب بايتات المسارات | Little-endian |
| بادئة المجال | 0x01 |
| خاتمة الحشو | 0x80 |

## الواجهات

- `Sum256([]byte) [32]byte` للبيانات الكاملة.
- `New()` و`Write` و`Sum` و`Reset` لمعالجة البيانات على دفعات.
- البيانات المدخلة لا تُعدّل، و`Sum` لا يغيّر حالة المعالجة المتتابعة.

## الاستقلالية

لا تعتمد حزمة Keccak-256 على أي مستودع أو مكوّن آخر من SILA. تستعمل
مكتبات Go القياسية فقط، ولا تتطلب شبكة أو مفاتيح أو معاملات أو كتلاً.

## شروط الاعتماد

1. اجتياز المتجهات المرجعية والتحقق المستقل من الناتج.
2. اجتياز فحوص جميع حدود كتل الامتصاص والتجزئة المتتابعة.
3. مراجعة أمان مستقلة لمصدر الشيفرة وتنفيذها.
4. مقارنة أداء عادلة بتطبيقات مرجعية وبأحمال استخدام مماثلة.
5. تحديد ترخيص التوزيع وتثبيت الإصدار ووثائق التكامل.

**تنبيه:** نجاح اختبارات الصحة الحسابية لا يثبت الأداء المتفوق أو السلامة
الإنتاجية. أمن طبقات SILA الأخرى يعتمد على مواصفاتها المستقبلية.
