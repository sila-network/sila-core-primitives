# SILA Keccak-256 V1.1 — المواصفة المرجعية

**الحالة: مسودة تقنية، غير معتمدة للإنتاج.**

## الوظيفة

حساب بصمة Keccak-256 لبيانات بايتية محددة بدقة. البصمة طولها 32 بايت.
هذا التنفيذ يحافظ على نفس نتائج خوارزمية Keccak-256 المعروفة، ولا يبتكر
خوارزمية تشفير جديدة. تختلف Keccak-256 عن SHA3-256 في قواعد الحشو.

## المعايير المثبتة

| العنصر | القيمة |
|---|---|
| الخوارزمية | Keccak-256 |
| التبديل الداخلي | Keccak-f[1600] |
| الجولات | 24 |
| معدل الامتصاص | 136 بايت |
| السعة | 512 بت |
| طول الناتج | 32 بايت |
| ترتيب بايتات المسارات | Little-endian |
| بادئة المجال | 0x01 |
| خاتمة الحشو | 0x80 |

## الواجهات

- `Sum256([]byte) [32]byte` للبيانات الكاملة.
- `New()` و`Write` و`Sum` و`Reset` لمعالجة البيانات على دفعات.
- البيانات المدخلة لا تُعدّل، و`Sum` لا يغيّر حالة المعالجة المتتابعة.

## التنفيذ

- **نواة AVX-512** (amd64 مع AVX-512F/VL): كل مسار من المسارات الـ25 في سجل XMM مستقل طوال الجولات الـ24. π إعادة تسمية سجلات في وقت التوليد، وθ وχ تعليمة `VPTERNLOGQ` واحدة لكل مسار، وρ تعليمة `VPROLQ` واحدة لكل مسار.
- **نواة Go محمولة** لكل المعماريات الأخرى أو مع `-tags purego`: جولتان مفكوكتان، والحالة تُعالج في مكانها، مع lane complementing.
- النواتان **مولَّدتان** بالأداة `internal/gen` من المواصفة: إزاحات ρ وثوابت الجولات تُحسب من تعريفها الرياضي، وأي ملف مولَّد قديم يُفشل الاختبارات.
- يُختار المسار مرة واحدة عند التحميل عبر CPUID/XGETBV، والنتيجة متطابقة بايتاً ببايت في المسارين.

## الاستقلالية

لا تعتمد حزمة Keccak-256 على أي مستودع أو مكوّن آخر من SILA، وتستعمل مكتبات Go
القياسية فقط. وحدة القياس `benchmarks/geth-compare` منفصلة، ولا تضيف اعتماديات إلى
الحزمة. لم تُنسخ شيفرة من go-ethereum أو غيره.

مسار الوحدة: `github.com/sila-network/sila-core-primitives`.
